Moderation before scale.

A Sheets-first admin surface for reports, pending review, verification notes, seed-content policy, and funding/investor caution. Secure role-based admin can be added later without throwing this workflow away.

Funding disclaimer

Funding and investor records are discovery surfaces only. They are not investment advice, recommendations, offers to sell securities, legal advice, tax advice, or diligence.

Admin model

Reports and action notes are append-only records. Content hiding is controlled by moderation fields in the Sheet until a secure admin auth layer exists.

Event source rule

Organizer source requests can be reviewed in Sheets, but OAuth tokens and API keys should only be stored in Apps Script Properties or a future secure auth store.
