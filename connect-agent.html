Developer setup and connection compatibility

Using EA in a regular ChatGPT project?

Add the Founders & Builders connection to EA’s chat to read public setup guidance, the Agent Card, and explicitly approved public opportunity and capability cards. The discovery tools cannot read your private tasks or submit questions. GitHub access provides code context; it does not create a live platform connection.

Private coordination from ChatGPT needs a compatible owner-authorization connection. The current limited bearer credential works with HTTPS-capable clients; it is not a drop-in ChatGPT MCP login.

For an HTTPS-capable EA: three steps

  1. Choose a contribution in your workspace and enable Coordinate with me through A2A on a new, limited grant.
  2. Give EA the connection setup packet and put the credential in its secure settings separately.
  3. Have EA send the sample question. Open Agent requests, respond, then have EA retrieve the answer.

The setup packet contains no credential. EA needs an HTTPS request tool for this pilot; its existing MCP connection alone does not expose these A2A methods.

Opt-in opportunity discovery

Owners can approve a short public opportunity or capability card from their workspace. Published beta tasks and discoverable beta profiles stay out of public agent discovery until that separate approval. Only selected public fields are exposed; full briefs, private ideas and conversations stay protected.

Private A2A pilot

The owner-handoff endpoint is deployed. A real JIDOKA EA host acceptance test remains pending.

Questions appear under Agent requests in your signed-in workspace. This first loop is between an agent and its own verified owner. It does not contact another founder or accept work automatically.

Read the Agent Card. Use A2A-Version: 1.0 with SendMessage, GetTask, and CancelTask. Streaming, webhooks, and file transfers are not supported in this pilot.

For agent builders

Connection capabilities and release status · Existing JSON command reference

The deployed MCP adapter uses stateless HTTP with an owner-issued bearer credential. It does not yet provide OAuth onboarding or claim compatibility with every agent client. The private A2A pilot lets your agent ask you a question, track the request, receive your response, or cancel. Enable “Coordinate with me through A2A” when issuing a new credential. Existing credentials do not gain this permission. Public discovery includes only separately approved cards. Automated ecosystem coaching remains a future milestone.

Private projects and participant conversations are not a public agent directory. Matching and wider discovery require explicit opt-in; connection does not grant global search.
